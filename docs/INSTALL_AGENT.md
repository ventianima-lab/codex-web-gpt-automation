# 설치 계약

[최초 설치 가이드](FIRST_INSTALL.md)와 [공통 정책](AUTOMATION_POLICY.md)을
따릅니다. 사용자가 설치를 요청하면 저장소 checkout과 lifecycle 설치를 진행한
뒤 `python onboard.py start --root <프로젝트-폴더>`로 연결 설정을 이어갑니다.
기존 진행은 `python onboard.py resume`으로 복구합니다.

처음에 필요한 사용자 선택은 프로젝트 폴더, 고정 주소 공급자, 선택형 Local
Multi-GPT 사용 여부입니다. 암호·토큰·쿠키는 묻거나 기록하지 않습니다.
로그인, 앱 등록, OAuth 승인, 계정·맞춤화·권한 설정은 사용자가 처리합니다.

기존 승인 폴더와 인증을 보존합니다. 필요한 설정과 실제 앱 읽기를 한 번 확인하고
정상 단계를 반복하지 않습니다. HTTP health나 사용자 등록 확인만으로 실제 파일
읽기에 성공했다고 하지 않습니다. 강제 도구 순서·감사 영수증 세 개·필수 결과
마커는 요구하지 않습니다.

정상 실행은 임시채팅, 명시적 **최신 → Pro (6 Pro)** 선택, 결과의 영구 저장,
소유한 탭 종료 순서입니다. Oracle 호환 carrier는 `gpt-5.6-sol` /
`model_strategy=current` / `thinking_time=pro`이며 숫자 GPT-5.6 선택이 아닙니다.
알 수 없는 CLI 모델 이름을 만들지 않습니다. 오류에는 같은 실행을 회수하고
자동 재전송하지 않습니다.

프로젝트별 자동화 중복 규칙은 공통 정책 참조로 통합하되, 고유 테스트와 안전
제약은 남깁니다. 설정된 지휘 모델과 사용자 승인 작업 범위를 바꾸지 않으며
CGW 경로를 복원하지 않습니다. 과거 실행 기록과 원래 권한은 보존합니다.

소스 수정, 배포, 연결 검증, 릴리스 완료를 구분하여 실제 확인한 상태만 보고합니다.
