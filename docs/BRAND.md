# Brand guide

## Name

- Product: **Agent Web GPT Automation**
- Repository and package: `agent-web-gpt-automation`
- Short descriptive phrase: **guarded, recoverable web ChatGPT execution for
  local agent projects**
- ChatGPT app name used by setup examples: `codex`

The bundled lifecycle installer and native subagent helpers still target Codex,
while Oracle dispatch and DevSpace workspace execution are usable by other
agents. Keep the manually registered `codex` app name and `codexpro-*` internal
schemas, receipts, service labels, plugin IDs, and frozen recovery assets stable
for backward compatibility.

This is a community project and must not be presented as an official OpenAI,
Oracle, or DevSpace product.

## Visual idea

The mark combines two code brackets into a guarded portal. Two edge nodes and a
central spark represent a controlled handoff between a local agent, a web GPT
session, and an approved workspace.

## Palette

| Token | Hex | Role |
|---|---|---|
| Midnight | `#0B1020` | Primary dark, local guard |
| Teal | `#2DD4BF` | Active bridge, approved path |
| Violet | `#8B5CF6` | Web intelligence, execution spark |
| Slate | `#475569` | Secondary text |
| Cloud | `#F8FAFC` | Light surface |

The mark itself uses flat colors and must remain legible at 32 px. Decorative
background gradients may appear in banners, but not inside the core mark.

## Usage

- Preserve the mark's aspect ratio and clear space of at least one node radius.
- Use the mark without text below 160 px wide.
- Do not rotate, outline, add shadows, recolor individual nodes, or combine it
  with the OpenAI knot, GitHub Octocat, or another product logo.
- Keep README claims factual and link operational detail to its canonical doc.
- Use “web ChatGPT” for the execution environment and “Web Multi-GPT” only for
  the independent multi-session mode.

## Image-generation provenance

The initial symbol direction was generated with OpenAI's built-in image tool
from an original project brief. The committed SVG mark was redrawn as simple
project-owned geometry for scalability, exact colors, and text-free reuse.
